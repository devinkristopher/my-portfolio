# Devin Rogers — Project Portfolio

[Visit the portfolio website](https://devinkristopher.github.io/my-portfolio/)

Software, analytics, AI/ML, and cloud coursework organized by area. Existing repositories retain their original history. Course-provided scaffolding and partial recoveries are identified in each project’s README.

## AI, Machine Learning & Computer Vision

- **[PAMLA · Predictive Agriculture Assistant](https://github.com/devinkristopher/PAMLA)** — A locally hosted soil-moisture forecasting assistant connecting environmental telemetry, machine learning, a stateful prediction API, and a local LLM interface. *TripleTen capstone + continued development.*
- **[Megaline Plan Classification](https://github.com/devinkristopher/megaline-plan-classification)** — Classifies subscriber plans from usage patterns, compares models, and evaluates a held-out test set. Separate from the Megaline statistical-analysis project. *TripleTen coursework.*
- **[BetaBank Customer Churn](https://github.com/devinkristopher/betabank-churn-classification)** — Explores class imbalance, feature engineering, and classification models using F1 and ROC AUC. *TripleTen coursework.*
- **[Insurance Charges Regression](https://github.com/devinkristopher/insurance-charges-neural-network)** — Uses a neural network to predict recorded insurance charges, with preprocessing and regression evaluation. The target is charges, not personal health risk. *TripleTen coursework.*
- **[Computer Vision: Age Estimation](https://github.com/devinkristopher/computer-vision-age-estimation)** — Explores image-label distributions and transfer learning with a ResNet50 regression model, including limitations of age estimation. *TripleTen coursework.*
- **[Film Review Sentiment Analysis](https://github.com/devinkristopher/film-review-sentiment-analysis)** — Normalizes movie-review text and compares sentiment classifiers with saved evaluation results. *TripleTen coursework.*
- **[Coloops · Retrieval QA](https://github.com/devinkristopher/coloops-retrieval-qa)** — Retrieves data-center operational guidance from an illustrative knowledge base and extracts answers from relevant context. A retrieval and extractive-QA prototype. *TripleTen coursework.*
